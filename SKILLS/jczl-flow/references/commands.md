# Commands

Owner of: the index of every command, by topic.

Run `jacazul flow help <command>` for the syntax, prerequisites, effects, and
examples of any command.

## [Initiatives](initiatives.md)

| Command | Purpose |
|---|---|
| `plan` | Create an initiative and chained tasks (alias: initiative, ini) |
| `goal` | Set an initiative goal |
| `organize` | Reorder pending tasks within one initiative |
| `plans` | List initiative summaries (alias: inis, initiatives) |
| `backlog` | Hide an initiative from default dashboards |
| `activate` | Restore a backlog initiative |
| `roadmap` | Manage the project roadmap ledger |
| `rename` | Rename an initiative |

## [Tasks](tasks.md)

| Command | Purpose |
|---|---|
| `execute` | Start a ready task |
| `outcome` | Record the result required for completion |
| `done` | Complete a task and expose ready work |
| `reopen` | Return a completed task to pending |
| `discard` | Discard a task with an audit outcome |
| `commit` | Draft a conventional commit from focus |
| `next` | List ready tasks |
| `amend` | Correct a task description or ticket |
| `urgent` | Raise task urgency |
| `block` | Add a task dependency |
| `unblock` | Remove a task dependency |
| `wait` | Postpone task readiness |
